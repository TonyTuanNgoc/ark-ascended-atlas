# Ascended 0.12.0 (13) — map filters and full-body creature artwork

Standalone native iPad app, branch `codex/ascended-ipad-dev-20261003`, based on fetched `196711721fc9e478c35b4ade0e63d7f618bdf8c3`. This release deploys by cable to Tony's iPad. No TestFlight or standalone web domain; no Tony OS files changed.

## Result

Moved map layer selection, all/none, location search and zoom/reset into a right-hand scrolling rail. Obelisks are distinct from boss encounters. Resources have pictured per-type filters, map-scoped offline coordinates and tap popups. The 45,280 resource nodes come from public Wikily ASA resource dumps: Ragnarok 21,212; Island 11,092; Center 12,976. Invalid positions outside 0–100 were excluded (1/5/0). At distant zoom the viewport groups nodes into 48-point cells; the pin and its GPS remain an actual representative source node, never a fabricated averaged coordinate. Cluster counts include the currently selected resource types. Zoom reveals smaller geographic groups. Cave resources are identified in the popup, and the resource layer starts hidden to avoid covering terrain. This is source dataset coverage, not an in-save field survey; cave/harvest classes and game GPS/map coordinate discrepancies can affect use.

Replaced the soft Ragnarok terrain texture with the genuine 2048×2048 ASA map from https://ark.wiki.gg/images/Ragnarok_map_ASA.jpg?71a238 . The replacement has more useful terrain detail despite its lower nominal dimensions; it is not an 8K reconstruction. Island and Center terrain stay unchanged. White map names now have a thin black outline, no black label rectangles; nearby names suppress collisions while marker menus retain all nearby points. Circular entrance pictures clip properly to the round pin. Existing GPS anchors, map cover/pan behavior and map-scoped progress are retained.

Added 81 transparent, coloured contextual creature/boss images, drawn with scale-to-fit in army, encounter, hazard and other visual facts. Full-body source selection prioritises complete feet, tails, wings and tentacles. Replaced cropped references for Carcharodontosaurus, Acrocanthosaurus, Basilosaurus, Ceratosaurus, Deinosuchus, Deinotherium, Broodmother, Helicoprion, Tusoteuthis and others. Library `CreatureAvatar`/large `CreaturePortrait` retain their existing game photographs rather than substituting a head icon or contextual cutout. Black fur/rock stays black; molten lava and fire remain orange/red. Creature quantity badges sit below the picture rather than covering feet/tails; item badges retain their compact overlay.

Original transparent game renders are copied directly when available. Other assets use source-referenced imagegen background extraction. Some complete ASA model images had red developer paint-region highlights; imagegen restored those regions using a gameplay colour reference while retaining observed model geometry. These edited extractions are not pixel-identical official renders and should not be described as such. No missing body parts were intentionally reconstructed: pose occlusion and the buried part of an Iceworm remain source limits. Spirit bear/wolf use their actual ASA encounter frames, Queen uses its actual ASA picture, Polar Bear uses its own source rather than a normal Dire Bear duplicate. Full provenance/method/prompt/hashes are internal in `2026-10-04-creature-cutout-sources.json`.

Twenty of the 33 mapped entrance/approach points have individually reviewed actual ASA photos or licensed video frames. Frames are unmodified; the app crops them at display time into circular pins. Video GPS often measures the creator's camera position; record the distinction instead of moving the entrance pin to an interior or artifact coordinate. Multiple Center Jungle doors were matched using on-video map readouts. Coordinates are unchanged in this release.

## Remaining source limits

Thirteen entrance points still have neutral cave symbols because a frame has not been matched confidently to that exact doorway: Ragnarok Carnivorous water/swamp alternatives, Frozen foot entrance, Wyvern; Island Lower South, North East, Lost Faith and Lost Hope; Center both Cliffside points, Floating and both Underground points. Existing cave walkthroughs remain available. Do not reuse an arbitrary cave photo or an ASE door image under an ASA coordinate. The precise list is in `2026-10-04-map-visual-validation.json`.

The complete visual-fact catalogue has more creatures than those referenced by current contextual guides. The cutout audit checks the current contexts and direct images; new future contexts may require additional body PNGs. Library missing-photo states (13 existing entries), lower-resolution base images and the existing source-footage limitations remain unchanged. Iceworm's generic hazard fact has no specific image asset; the Queen is separate. Existing 467 source-native HD HEVC cave loops and their posters remain untouched.
