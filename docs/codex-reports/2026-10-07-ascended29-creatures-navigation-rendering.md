# Ascended 0.28.0 (29) — creature profiles, grouped navigation and immediate map overview

Creature library removes its duplicate heading/map subtitle. The centered module heading now reads Dinosaurs & Creatures beside the map catalogue's total count (159 on Ragnarok). The existing searchable roster and filter IDs are preserved; all category chips receive recognizable illustrated SF Symbols. The current-map selector remains the only map-name context above the library.

Existing dossier silhouettes remain intact. Alpha uses bright red, Corrupted bright violet, and Fire/Lightning/Poison/Ice Wyverns use warm orange, blue-violet, lime and pale cyan recognition accents. These are UI identification colours based on characteristic type/glow, not a promise about an individual creature's mutable skin regions. Ordinary and uncertain variants remain white. Alpha precedence is retained for Alpha Fire Wyvern. References: https://ark.wiki.gg/wiki/Alpha_Creatures , https://ark.wiki.gg/wiki/Corrupted_Creatures , https://ark.wiki.gg/wiki/Wyvern . No creature statistics, source catalogues, recipes or gameplay formulas changed.

Landscape profiles use three top-aligned columns: Taming, Base stats, and Loot & immobilization. Diet, taming status, method and labelled numeric stats use compact inline fact tiles. Food, drops and immobilization keep their real item artwork. Practical notes and source link follow the columns. Narrow windows stack one column instead. Unknown profiles retain their explicit missing-information state; no details are invented. Achatina was visually reviewed with all principal sections in the same viewport.

The module rail now has three subtly boxed groups separated by vertical dividers: Story / Atlas; Farming / Equipment / Base Locations; Creatures / Artifacts & Caves / Bosses. Story replaces ASA Story. Stable navigation identifiers and map selection storage remain unchanged.

The black-tile opening effect came from rendering the entire map solely through asynchronous CATiledLayer regions with an opaque background. The map now layers a synchronously decoded 1280px overview below transparent high-resolution detail tiles. Tile fade duration is zero. Both share original image-local bounds; GPS, pins and long-press transforms remain the same. The detail renderer still crops original source pixels at zoom levels rather than discarding source detail. Pixel QA checks the first rendered overview frame, transparent detail backing, zero fade and Retina crop/GPS geometry.

Initial UI checks exposed two test selectors that incorrectly counted the map-picker label as a redundant heading and looked for an individual text node inside a combined item tile; those selectors were corrected.
